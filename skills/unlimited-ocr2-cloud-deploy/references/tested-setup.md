# 来源、实测环境与证据范围

## 原始部署

在 2026-10-29 的授权临时云主机部署中记录：

- Ubuntu 22.04.5 LTS x86_64，RTX A6000 48GB（SM 8.6）。
- NVIDIA 驱动 580.126.20，CUDA 13.0 支持；约 94.3 GiB 主机 RAM，6 个逻辑 CPU。
- Python 3.11 venv；PyTorch 2.13.0+cu130；Transformers 5.12.1；定制 SGLang 0.5.20.dev13+g75b9b06b02。
- 模型快照 `c14071b549f4fcab10909f3c4acc6a2edb366947`；窗口 10、静态显存比例 0.70、小批次 CUDA Graph、Web 单文档执行队列。

这说明该组合曾跑通，不说明所有 48GB GPU、其它系统或更新依赖都已验证，也不是最低硬件清单。

## 先前实际完成的验证

单页中英混排、3 页跨页表格及 12 页长文档均完成真实推理。新增视频工具的 12 页 Gundam/Base 对照使用相同准备图像指纹，均结束 12 页并含最后页标记；资源记录、导出、CER 算术和同输入对照的 17 项功能检查通过。原任务还确认了跨 10 页窗口的输出与 KV 复用日志。

人工按原创 3 页示例原文填写末页参考，忽略空白后 133 字符，CER 为 0。只代表该页和该归一化规则；不代表通用准确率、真实业务、手写或任意长文档性能。

公网 HTTPS、登录保护、loopback 监听以及运行时安全排空均曾检查。没有把原云主机地址、密码、用户文档、任务历史或完整私有运行目录带入公开仓库。

## 打包时的变化与限度

本 skill 保留原 Web/推理配置与 212 项锁文件。公开版新增只读预检、准备目录不覆盖保护、首次安装遇已有部署/代理即停止的保护，以及系统清单中的显式 ufw 依赖。第三方后处理从固定提交取回原始字节；原备份只多一个末尾空行，功能代码一致。

公开版还让 smoke test 在缺少已知文字或出现截断等警告时返回失败，避免只以任务完成和页数作判断。这些打包改动做本地无 GPU 检查；没有为发布 skill 重新部署或中断现有云模型。新目标仍必须真实 GPU 验收。参考资料和仓库检查通过，也不能替代该验收。
